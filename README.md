## 🧠 Core Features & Technical Innovation

Aegion Wealth isn't just a tracking app; it's a comprehensive algorithmic trading and wealth management ecosystem.

* **Advanced AI Forecasting:** Utilizes Long Short-Term Memory (LSTM) neural networks to predict market momentum and forecast returns.
* **Dynamic Asset Allocation:** Autonomous portfolio rebalancing using quantitative financial models (including VaR and CVaR risk assessment).
* **High-Performance Backend:** A robust FastAPI infrastructure handling real-time data streams and complex mathematical computations with zero bottlenecks.
* **Native Android Excellence:** Built with Kotlin, Jetpack Compose, and a clean MVVM architecture for a buttery-smooth, responsive mobile experience.
* **Institutional Security:** Secure authentication and strict data handling protocols.

## 🛠️ Tech Stack

**Backend & Quantitative Engineering**
* **Language:** Python
* **Framework:** FastAPI
* **AI/ML:** TensorFlow/Keras (LSTM), Scikit-Learn
* **Finance Models:** Modern Portfolio Theory, Risk Assessment (VaR/CVaR)

**Frontend & Mobile Development**
* **Platform:** Native Android
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Architecture:** MVVM (Model-View-ViewModel)
* **API Integration:** RESTful API consumption
